# SailPoint University — ISC Setup Study Book

Personal English study notes for **Set Up and Administer Identity Security Cloud**.

- 13 teaching modules and 70 lessons, in verified course order
- 26,237 words of paraphrased explanations, examples and procedural notes
- 501 saved original English image files placed with related content
- Expanded explanations from inspected tabs, accordions, markers and process panels
- Searchable offline HTML, Markdown notes and per-lesson coverage records

## Read offline

Download or clone this private repository, then open **study/index.html** in a browser. Keep the `study` folder and its subfolders together. The search field highlights matches across teaching chapters. Click an image for a larger view. Use your browser's print command for a reading layout.

GitHub's file viewer displays HTML source; open the downloaded file locally to read the rendered book. Individual Markdown notes are available under `study/modules/01` through `study/modules/13`.

## Coverage and limitations

Read **study/coverage-report.md** for known omissions and source inconsistencies. All teaching lessons have notes, but the source course is not fully archived: background artwork, complete audiovisual narration, external resources and executable activities are not preserved. Modules 7 and 13 retain earlier captures with incomplete original-image inventories. The closing Next Steps page is included with its failed image download documented.

Course information reflects the viewed version. Interface examples are not independently validated current product specifications. No quiz or assessment was submitted, no messages were sent, and no live tenant configuration was changed during preparation. Normal reading may update LMS progress.
